# data/sources/money

Owner-supplied money images, one folder per currency code. Files here are only used when data/overrides/money.json points at them (src: "data/sources/money/MXN/<file>"), and only with a written authorization or published terms recorded in that entry. MXN/captures/: 1:1 frames from Banco de Mexico's own video (youtu.be/K8odC5acil4 at 0:03), to be cropped into MXN/<denomination>-anverso.jpg. Nothing in this folder is a scan from a catalogue or a collector.
